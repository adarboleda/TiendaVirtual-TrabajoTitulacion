## Instrucciones para Aplicación del Formulario

### Método de Recolección

1. **Google Forms** (Recomendado)
   - Crear formulario con todas las preguntas
   - Configurar validación de respuestas
   - Exportar resultados a Excel/Google Sheets

2. **Microsoft Forms**
   - Similar a Google Forms
   - Integración con Excel

3. **TypeForm** o **SurveyMonkey**
   - Interfaces más atractivas
   - Análisis automático de resultados

### Tamaño de Muestra Recomendado

- **Mínimo**: 30 usuarios
- **Óptimo**: 50-100 usuarios
- **Diversidad**: Incluir diferentes perfiles (clientes, vendedores, administradores)

### Tiempo Estimado de Respuesta

- **15-20 minutos** para completar el cuestionario completo
- Considerar dividir en secciones más cortas si es necesario

### Cálculo de Resultados

#### Por Pregunta
```
Promedio = Suma de todas las respuestas / Número de respuestas
```

#### Por Dimensión
```
Promedio de Dimensión = Suma de promedios de preguntas / Número de preguntas en la dimensión
```

#### Interpretación General
- **1.0 - 2.0**: Nivel muy bajo (requiere mejora urgente)
- **2.1 - 3.0**: Nivel bajo (requiere mejoras significativas)
- **3.1 - 3.5**: Nivel aceptable (mejorable)
- **3.6 - 4.0**: Nivel bueno (pequeñas mejoras)
- **4.1 - 5.0**: Nivel excelente (mantener)

## Anexo: Plantilla para Google Forms

### Configuración Recomendada

1. **Título**: Evaluación de Usabilidad - Sistema E-Commerce Siachos
2. **Descripción**: 
   ```
   Estimado/a participante,
   
   Gracias por dedicar su tiempo a evaluar nuestro sistema. Sus respuestas 
   nos ayudarán a mejorar la experiencia de usuario. El cuestionario tomará 
   aproximadamente 15-20 minutos.
   
   Toda la información será tratada de forma confidencial y anónima.
   ```

3. **Configuración**:
   - Recopilar direcciones de correo: NO (para mantener anonimato)
   - Limitar a 1 respuesta: SÍ (si quieres evitar duplicados)
   - Mostrar barra de progreso: SÍ
   - Aleatorizar orden de preguntas: OPCIONAL

4. **Formato de Pregunta Likert en Google Forms**:
   - Tipo: **Escala lineal**
   - Rango: 1 a 5
   - Etiqueta 1: "Totalmente en desacuerdo"
   - Etiqueta 5: "Totalmente de acuerdo"
